# Frontend (React + TypeScript + Vite)

Conway’s Game of Life UI for the monorepo API.

From the **repository root**:

- Dev: `npm run dev:frontend` (ensure the API is running; Vite proxies `/api` to port 5021).
- Build: `npm run build:frontend`
- Optional: set `VITE_API_BASE_URL` when the API is not proxied (e.g. production).

See the root [`README.md`](../README.md) for full monorepo instructions.
